# Supply Chain Analytics Dashboard

## Overview
This project focuses on analyzing supply chain data to improve operational efficiency, reduce risk, and support decision-making. Using a real-world dataset, I built an interactive Power BI dashboard to track key metrics such as sales, inventory, supplier performance, and logistics costs.

## Objectives
- Monitor inventory levels and identify stock shortages
- Analyze supplier performance and risk factors
- Evaluate transportation and logistics costs
- Track revenue, profit, and demand trends

## Tools & Technologies
- Power BI
- Excel
- DAX (Data Analysis Expressions)
- Data Cleaning & Transformation (Power Query)

## Key Features
- KPI cards for Revenue, Sales, and Profit
- Inventory status tracking (Low Stock vs Healthy)
- Supplier risk analysis using lead time and defect rate
- Logistics cost analysis by transportation mode
- Interactive dashboard with filters for Product, Supplier, and Location

## Key Calculations
- Profit = Revenue - Manufacturing Cost - Shipping Cost
- Profit Margin = Profit / Revenue
- Risk Score = Lead Time × Defect Rate
- Inventory Status classification

## Business Insights
- Identified high-risk suppliers based on defect rates and lead times
- Highlighted products with low inventory levels requiring replenishment
- Analyzed cost differences across transportation modes
- Evaluated profitability across products and supply chain operations

## Outcome
This project demonstrates the use of data analytics to optimize supply chain performance and support data-driven decision-making.
